# 最终决定

**NO-GO · 用 Mendeley v1 单独支撑原拟定的跨温室、跨年份水分状态预测与解释可靠性课题。**

**CONDITIONAL GO · 把该包用作可复现的压力室标签对齐和方法预研。** 获得足量、可追踪的独立采样日后，才将忠实性和扰动稳定性升级为修士课题主实验。

两处设施、六个来源年份与 1,695,315 个源观测行，只提供 **3 个有效水势采样日、22 个时点、62 个测量行和 212 个有限分层 MPa 值**。Heverlee 只有 2022-04-07，Meerle 只有 2023-09-14 和 2023-10-12。`WP_2024.xlsx` 全表等于 2023 年水势表，2022 的 CSV 与 XLSX 也全表等值。三个采样日的环境窗口可配对，时区和设备同步未经外部核实。 [目标审查](target_label_audit.csv) · [完整审查](DATA_AUDIT_REPORT.md)

| 必答问题 | 判定 |
|---|---|
| 1. 能支撑温室番茄水分状态预测吗 | **NO-GO**。只能对少量事件做当前状态配对或描述性低频回归预研。连续、未来或可泛化预测无足够监督。 |
| 2. 能支撑多变量时序模型吗 | 环境序列层面可构造多个区间。以实测茎水势作为监督标签时 **NO-GO**，输入行数不能弥补标签稀疏。 |
| 3. 能开展解释忠实性研究吗 | **CONDITIONAL GO**，限管线和负对照演示。正式解释方法比较需先有可靠独立测试和表现可验证的预测器。 |
| 4. 能开展解释稳定性研究吗 | **CONDITIONAL GO**，限真实缺失形态下的描述性压力测试。跨批次稳定性需要独立活动。 |
| 5. 能进行农学知识一致性验证吗 | **CONDITIONAL GO**，限空气 VPD 和辐照的条件性软检查。根区供水和生理滞后缺少可辨识证据。 |
| 6. 能做跨地点验证吗 | **NO-GO**。两地标签各来自独有年份、不同仪器布局，且只有 1 日和 2 日。 |
| 7. 能做跨年份验证吗 | **NO-GO**。无同地两个独立标签年；2024 不提供独立测量标签。跨地点兼跨年份也不能解释为可推广结果。 |
| 8. 需要其他公开数据集吗 | 若保留真实茎水势目标或正式评价，需要补同协议实测标签，可来自独立公开数据或获授权研究数据。根区、水势或代理字段须逐表核验。 |
| 9. 应该继续当前题目吗 | **暂不以原题承诺未来预测和跨温室泛化**。可以将解释可靠性保留为信息学主轴，按获得的数据限定目标和范围。 |
| 10. 是否要缩小范围或改目标 | **需要**。首选有独立数据支撑的事件级茎水势估计，聚焦忠实性与现实传感扰动。若仅能取得连续 RSD、萎蔫或基质水分，题目应明示代理对象、测量定义和与茎水势的区别。 |

申请讨论可用的条件性题目为 **「温室番茄茎水势估计模型的归因忠实性与传感扰动稳定性评价」**。将实测标签覆盖、仪器/时钟可比性和跨独立活动切分设为立项前提。若峰野实验室只有同棚 RSD，可围绕该代理量设计解释诊断，与其既有 Transformer 域适配工作的区分在于同模型的归因忠实性、现实缺失下稳定性及可证伪的检验，而非新增预测模型。 [峰野团队 Transformer 论文](https://doi.org/10.3390/technologies12070094) · [文献排重](RELATED_WORK.md) · [实验方案](EXPERIMENT_PLAN.md)
