- Parma 60 分钟验证 MAE 依次为 0.2900、0.4190、0.5124，Persistence 在 2024 验证也胜出。2025 五条测试线均复现这个排序的首位。高水平值 R² 与持续性很强的标签并存，不能代替增量预测检验。三个提前量均未展示跨季学习增益。
- WUR 60 分钟的 LightGBM 配对改善在 Reference 为 0.1704，95% 区间 [0.1202, 0.2185]，在 TheAutomators 为 0.0695，区间 [0.0375, 0.1018]。Ridge 在 60 分钟也于两个隔间改善 MAE 与 RMSE，增益较小。30 分钟的 TheAutomators 区间 [−0.0126, 0.0326] 跨零。60 与 120 分钟的 LightGBM 在两个测试隔间的改善区间均为正，支持小时级提前量。对实际灌溉决策收益、测试隔间之外的设施以及完整历史之外的可靠性，证据限于本实验的适用范围。 [各角色汇总](baseline_metrics.csv) · [各季、线、探头、隔间与岩棉板的 MAE、RMSE、R²、Skill](per_group_metrics.csv)
- 60 分钟配对缺失试验在 WUR 中使 LightGBM 的 MAE 从 0.7152 上升到 7.4188（移植模式）和 6.5296（匹配随机）。它在完整历史上通过预测门槛，在压力测试的两种掩码下失去对 Persistence 的优势。细节见 [MISSINGNESS_PROTOCOL.md](MISSINGNESS_PROTOCOL.md)。

## 复算

从项目根目录运行。需要 Python 3.12 和阶段二已验证的原包及 WUR 解压成员。以下使用环境外独立虚拟环境，默认只写 `baseline_validation` 下的结果 CSV。可用 `--output` 指向单独目录并比较结果。原始数据、阶段二表与三份固定协议无需改动。

```powershell
py -3.12 -m venv .venv-stage3
.\.venv-stage3\Scripts\python.exe -m pip install -r baseline_validation/scripts/requirements.txt
$env:OPENBLAS_NUM_THREADS='2'
$env:OMP_NUM_THREADS='2'
.\.venv-stage3\Scripts\python.exe -B baseline_validation/scripts/run_baselines.py
```

入口 [run_baselines.py](scripts/run_baselines.py) · [数据与建窗](scripts/prepare_data.py) · [缺失形态和配对掩码](scripts/missingness.py) · [固定依赖版本](scripts/requirements.txt)。记录清单、基线指标、分组指标、提前量表和五个缺失结果表由程序生成。测量字典及缺失对照设计是可审查的人工协议表。
