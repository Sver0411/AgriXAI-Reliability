# AgriXAI-Reliability · 第三阶段决策

| 数据集 | 决定 | 已验证范围 |
|---|---|---|
| Parma Evolving Testbed | **NO-GO** | 跨季短期学习预测未达门槛。2025 季留出后，两个学习模型在 30、60、120 分钟的总体 MAE 和 RMSE 都高于 Persistence |
| WUR Tomato Challenge 第二届 | **GO** | 在同设施、同茬次的不同隔间，60 分钟 LightGBM 通过完整历史预测门槛。仅覆盖公开五分钟岩棉含水量序列 |
| 项目第四阶段 | **以 WUR 启动** | 将 WUR 作为受控的岩棉归因与传感观测扰动实验。原先以 Parma 为主、WUR 为独立复现的双数据集方案尚未通过 |

## 八项问题

1. **Parma 的目标变量是否适合短期预测？** 同型号探头的土壤含水率输出足以定义和复算一个短期任务。2025 年 60 分钟 Persistence MAE 为 0.1653，Ridge 为 0.3891，LightGBM 为 0.6734，且两个学习模型在 5 条线均落后。当前数据和输入配置未验证跨季学习预测价值。2023 埋深记载冲突、2024/25 缺逐探头深度映射，也限制了对具体深度和绝对土壤 VWC 的解释。
2. **WUR 的岩棉含水量是否适合独立短期预测？** 适合。60 分钟 LightGBM 的测试 MAE 由 Persistence 的 0.8303 降至 0.7104，RMSE 从 1.2479 降至 1.1849。MAE Skill 为 +14.45%，MAE 改善 95% 周块区间 [0.0889, 0.1527] 岩棉体积百分点。
3. **独立测试单位够吗？** Parma 有三季但只有一个完全未见的测试季，五条测试线共享该季条件。足以评估这一次跨季迁移，无法估计跨年结果的重复性。WUR 有两个完整留出隔间，各含两通道，足以支持这个站点这次跨隔间评估。共享天气、单设施与单作物周期限制进一步外推。
4. **哪个模型稳定超过 Persistence？** WUR 60 分钟 LightGBM 在 Reference 和 TheAutomators 分别降低 MAE 22.86% 和 7.60%，两个隔间的周块改善区间均大于零。WUR Ridge 在两隔间也有较小且方向一致的 60 分钟增益。Parma 三个提前量没有学习模型过门槛。
5. **哪些提前量有价值？** WUR 的 60 和 120 分钟在两个测试隔间都有明确 MAE 增益。30 分钟总体改善，但 TheAutomators 的改善区间跨零。保留 60 分钟为主终点，120 分钟为补充。这里的价值指相对 Persistence 的误差增益，田间控制收益还没有检验。
6. **真实缺失形态会影响预测吗？** 移植训练记录中的可用性模式后，WUR LightGBM 的 60 分钟 MAE 增加 6.704 岩棉体积百分点，95% 区间 [6.532, 6.877]。Parma Ridge 增加 0.319 设备输出百分点，区间 [0.249, 0.395]。该结果来自带完整真值的配对压力测试，真实中断期间的反事实预测误差尚不可直接识别。
7. **能区分记录形态和随机缺失吗？** 在每窗每信号缺失数量完全相同的条件下，WUR LightGBM 的记录模式比随机模式多 0.889 个岩棉体积百分点 MAE，95% 区间 [0.747, 1.044]。Parma Ridge 差值为 −0.333 设备输出百分点，区间 [−0.450, −0.236]。两个方向都可区分，差值符号依赖数据域、掩码形态和模型。该试验保护了当前水分读数，并使用清洁输入训练的模型。
8. **能进入时序归因研究吗？** 可以从 WUR 开始，固定已验证的 60 分钟模型、隔间和观测扰动口径。先把完整输入的忠实性与扰动稳定性分开评价。高缺失预算下 WUR 的预测变化已很明显，因此“预测变化很小”的归因问题只能在随后显式量化并筛选的子集检验。公开 WUR 根区数据由三分钟转五分钟，具体重采样、时区和入库延迟未公开，在线原始设备级故障及真实网络机制尚无可验证的结论。Parma 暂不承担第四阶段的主要或双域复现任务。
