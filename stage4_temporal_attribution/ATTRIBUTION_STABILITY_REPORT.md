# 传感扰动与归因稳定性

384 个测试窗在两个提前量复用。B 的训练记录掩码每窗 2–26 格，均值 12.48/52 格（24.0%）。C 对每窗每信号精确匹配，包含阶段三首个实现及 29 个新固定种子实现。各随机实现先在窗口内聚合。原始观测中的连续空缺、移植的记录掩码和实验随机掩码分别保留。当前 WC 始终可见。 [固定协议](XAI_METHOD_DESIGN.md) · [Mask Manifest](mask_manifest.csv)

| 60 分钟 TreeSHAP | 0.6175 | 0.5233 | +0.0942 [0.0793, 0.1097] |

- 60 分钟 TreeSHAP 的 B−C 在 Reference 为 +0.0908 [0.0713, 0.1145]，在 TheAutomators 为 +0.0976 [0.0775, 0.1172]。按缺失预算分层，≤10%、10–25%、>25% 的差依次为 +0.3175、+0.0878、+0.0246。120 分钟总体跨零，低预算层仍为 +0.1287，高预算层为 −0.0325，提示结构效应依赖提前量、模型及遮蔽预算。
- 60 分钟纯时间排序中，B 与 C 的平均 Spearman 为 0.690、0.823，Kendall τ-b 为 0.594、0.728，Top-2 重合为 0.794、0.958。交组平均 Top-4 重合为 0.583、0.633，方向反转率为 30.63%、29.06%，归一化 L2 为 0.679、0.564，余弦为 0.707、0.776。交组的高 Spearman 可与明显的首选组变化及符号反转并存。
- 从完整输入到 B，60 分钟绝对归因的岩棉 WC 份额从 34.12% 升至 72.30%（C 为 62.79%），岩棉温度从 43.93% 降至 12.98%（C 为 21.42%）。60–50 分钟时间组的 signed 均值由 −0.310 变成 +5.349（C 为 +3.271），最大变化主要集中在岩棉 WC 与最旧时间的交组。预测分支可能直接利用 NaN 的树路由，归因反转的含义限于模型。 [带符号热图](figures/04_complete_perturbed.png)
- D 与 E 分别遮蔽 8、16 格；60 分钟交组 L1 为 0.4286、0.4298，平均绝对预测变化为 1.410、1.324 个百分点，不能把差异独立归结为同缺设备数。F 相同预算下，近期相对旧段使 60 分钟 TreeSHAP 交组 L1 低 0.2422 [−0.2589, −0.2263]，预测绝对变化低 5.957 个百分点。120 分钟的同一位置对照中，预测变化差为 −0.072 [−0.214, 0.069]，交组 L1 差仍为 −0.0327 [−0.0454, −0.0204]。 [扰动图](figures/03_perturbation_comparison.png) · [隔间图](figures/08_compartment_stability.png)

## 预测小变动时发生了什么

IUACAAS 验证集冻结小变化阈值 **≤0.25 岩棉体积百分点**，大预测变化阈值在 60／120 分钟分别为 **≥11.4644／≥3.2013**。大归因幅度漂移定义为交组 L1≥0.50。60 分钟 B 中，44 个低变化窗里有 **19 个（43.2% [28.1%, 60.5%]）** 的 TreeSHAP Top-4 有一个组更换。Reference 为 9/22，TheAutomators 为 10/22。44 窗中 **0 个**达到 L1≥0.50，L1 中位数 0.060、最大 0.488。大预测变化 105 窗全部达到 L1≥0.50。120 分钟 B 中 58 个低变化窗里 36 个更换 Top-4、仅 1 个达到 TreeSHAP 的大幅度门槛。零事件的经验 bootstrap 区间会退化，样本以外的风险仍不确定。

60 分钟 TreeSHAP 的 |Δ预测| 与交组 L1 的 Spearman 为 **0.895 [0.872, 0.913]**（B）和 **0.958 [0.949, 0.964]**（C 的逐窗均值）。120 分钟 B 为 **0.695 [0.630, 0.749]**。这组结果表明总体幅度共同变化，但排名对较小的输出移动仍敏感。单看相关性无法推断单窗机制，也无法区分遮蔽预算的共同驱动。60 分钟 B 和 C 的平均绝对预测变化为 7.813 与 6.427 个百分点，平均绝对误差增加 7.002 与 5.731 个百分点。120 分钟 B 的绝对预测变化和误差增量均低于 C，TreeSHAP 的总体 L1 差却跨零。 [预测—归因散点](figures/05_prediction_attribution_scatter.png) · [连续量和分层支持](prediction_relationship_summary.csv)
