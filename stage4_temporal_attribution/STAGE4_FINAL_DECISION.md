# AgriXAI-Reliability · 第四阶段决策

**CONDITIONAL GO。** 第五阶段有明确的验证问题：等预算下，记录形态能增加归因漂移，而对解释器忠实性的判定依赖替换质量和可干预范围。现有证据支持开展独立验证与协议对照，尚不足以提出一套已获支持的新解释算法。

| 问题 | 第四阶段判断 |
|---|---|
| 1. TreeSHAP 能解释 LightGBM 的实际行为吗？ | 能精确重构预测增量。原匹配替换下，60 分钟完整窗的 TreeSHAP 高优先删除 AUC 对随机优势区间跨零，插入有优势。边界调整后删插均优于随机。加法重构、局部对齐和删插回答不同的问题。 |
| 2. 时间归因稳定吗？ | 受条件约束。60 分钟时间组 Top-2 重合在记录和随机条件下为 0.794 和 0.958，交组 Top-4 进一步降至 0.583 和 0.633。 |
| 3. 记录形态更扰动归因吗？ | 60 分钟 TreeSHAP 交组 L1 增量相对随机多 +0.0942 [0.0793, 0.1097]，两个隔间一致。120 分钟 TreeSHAP 的总体差 −0.0026 [−0.0123, 0.0083]。分组遮蔽在两个提前量均显示记录形态更强。 |
| 4. 预测变化和解释变化一致吗？ | 60 分钟记录形态的 |Δ预测| 与 TreeSHAP 交组 L1 的 Spearman 为 0.895；总体幅度联系强。排名、符号以及分层反应有不同变化。120 分钟记录形态的预测变化比随机小，TreeSHAP 幅度差跨零。 |
| 5. 有预测稳定、归因不稳定吗？ | 有排序层面的证据。60 分钟记录形态 44 个预测变化≤0.25 个百分点的窗中，19 个更换一个 Top-4 组，0 个达到交组 L1≥0.50。120 分钟同条件为 36/58 更换、1/58 大幅漂移。 |
| 6. 哪种归因方法最忠实？ | 原近邻直接拼接下分组遮蔽更接近独立供体响应。但该规则有约一半异常边界。边界调整后，两方法的 60 分钟删插 AUC 差均跨零，分组遮蔽单组响应对齐更高，120 分钟完整窗 TreeSHAP 插入 AUC 更低。现有结果支持按干预和指标分开比较。 |
| 7. 哪种方法更敏感？ | 原协议下 60 分钟 B 的 L1 为 TreeSHAP 0.618、遮蔽 0.599，120 分钟分别为 0.361、0.525。边界调整后的遮蔽 B 为 0.678、0.615。对同一模型的敏感度判断会随解释定义、替换和提前量改变。 |
| 8. 有明确研究空白吗？ | 本案例的未决问题是区分真实可用性结构引发的归因排序变化与替换分布引发的忠实性偏差，并验证这种区分是否在独立设施或茬次复现。预测保持时解释漂移、条件移除和替换分布问题已有方法研究。 |
| 9. 值得提出新的评价方法吗？ | 值得先检验能否把小预测变化下的排名风险、幅度风险与可见值忠实性作为分开的判据，并报告更换替换规则后的结论。只有当这些对照在新的留出组仍暴露现有基准的具体失效，才有理由提出并比较新方法。 |
| 10. 具备进入第五阶段的条件吗？ | **有条件进入。** 先冻结边界质量门槛和不同替换机制，在独立站点或独立茬次复核等预算结构效应与排名变化。当前两个隔间共享设施与栽培周期。WUR 三分钟原始序列的重采样算子未知，缺失实验范围为发布记录模式移植与实验遮蔽。 |

既有的农业预测退化基准主要评价预测误差，时序解释文献已经研究条件移除和近乎不变预测下的解释稳定性。本研究能站得住的比较是固定一个岩棉预测器、按同窗等预算比较记录缺失形态，并同时检验归因变化和替换质量。WUR 的具体数值是本次验证结果，尚需独立数据确认其适用边界。 [第二阶段近邻排查](../dataset_scouting_round2/RELATED_WORK_UPDATE.md) · [WinIT](https://openreview.net/forum?id=C0q9oBc3n4) · [时序结构归因防御](https://doi.org/10.1016/j.patrec.2026.04.017) · [替换分布偏移](https://arxiv.org/abs/2106.00786)
