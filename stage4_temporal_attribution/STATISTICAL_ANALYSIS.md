# 配对统计与证据边界

全部测试来自 Reference 和 TheAutomators 的 384 个固定样本。两个岩棉板属于同一隔间。对每个提前量按共同导出钟面的 24 个日历周同步重抽 2,000 次，同周保留两个隔间、岩棉板和所有对应条件。输入在同板内不重叠，预测目标和农业过程仍可能相依。区间估计该时段的周间波动；周际相关、共同天气和隔间数量限制对新站点、茬次或设备的推断。 [样本表](frozen/sample_manifest.csv)

B 与 C 在同窗、同信号上预算精确匹配。C 的每个连续指标先取 30 次窗内平均；组发生率先逐实现判定，再累加窗内联合事件率与支持率。表中 `n` 为具有非零支持的不同窗口数，`eligible_equivalent` 是窗内支持率之和。配对差按样本连接之后取均值。曲线随机顺序同理先在窗内聚合 5 次。替换供体的两个反事实响应先逐窗聚合。周块同时保留各条件，重复数不计入独立样本数。归因相关性的常数向量、余弦的零向量和方向反转的无共同激活情况保留空值，指标分母可在结果表查看。

## 主效应

| 预先固定的对比 | 效应 [95% 周块区间] | 解释 |
|---|---:|---|
| 60 分钟 TreeSHAP 交组 L1，B−C | +0.0942 [0.0793, 0.1097] | 两个隔间方向相同 |
| 60 分钟完整输入交组删除 AUC，TreeSHAP 高−随机 | +0.0068 [−0.0219, 0.0345] | 原供体直接拼接，区间跨零 |
| 60 分钟完整输入交组删除 AUC，遮蔽高−随机 | +0.1611 [0.1305, 0.1909] | 原供体直接拼接 |
| 60 分钟 B 低预测变化窗中 Top-4 有更换，TreeSHAP | 19/44，43.2% [28.1%, 60.5%] | 排名事件，未触发幅度门槛 |
| 同组 L1≥0.50，TreeSHAP | 0/44 | 观测期零事件，经验区间退化 |

连续关系使用 Spearman，周块重抽后重排秩。60 分钟 B 的 |Δ预测|–L1 为 0.895 [0.872, 0.913]，但这一关联在不同模型、预算和指标下强度不同。当前 WC 与树基值固定时，预测差等于全部树归因的带符号差之和，预测与 TreeSHAP 并非独立测量；交组绝对量 L1 仍有不同的定义和可变的分母。观察到的关联无法识别因果路径。超过 0.50 的条件概率按验证阈值和支持周数分别列出。所有表同时报告两隔间，主比较之外的分层和额外提前量为探索性，区间未经多重性调整。 [连续关联与子组](prediction_relationship_summary.csv) · [分隔间统计](per_compartment_results.csv)

边界调整属于诊断后敏感性实验。它保留所有样本、同一个模型和主对照，改变解释和评价的替换规则。对应结果独立保存，不能用它回填原定主分析。两个规则的解释器比较说明报告范围需要同时指定替换规则、归因层级、可见性与忠实性指标。 [原比较](faithfulness_metrics.csv) · [边界调整比较](boundary_sensitivity_faithfulness.csv)
