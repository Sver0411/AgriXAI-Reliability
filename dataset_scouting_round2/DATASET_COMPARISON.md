# 候选数据集比较

分数为 12 项各 0–2 分，满分 24。原件可复算且适配记 2，部分适配、需要限定使用或仅有充分文档记 1，证据缺失或不满足记 0。可获取性、许可、连续性、采样、目标适配、标签密度、独立性、覆盖、质量、对齐、研究室匹配、创新空间分别评分。完整度证据来自已读文件或发布者的质量说明。分数是筛选记录，不是统计置信度；按目标重新排序时应优先检查标签类型和切分。 [逐项评分](dataset_feasibility_scores.csv)

## A–D 标签的证据口径

- **A 直接生理监督**包括实测叶/茎水势、实测液流、叶蒸腾和气孔导度。实测叶温和茎径可作为各自的回归目标；在水分胁迫任务中属于代理。电生理的输入为实测差分电位，其分类目标由灌溉和时段规则构造。
- **B 根区**包括土壤或岩棉含水、基质势和营养液信息。校准和基质不同会改变量值及传输过程。土壤与岩棉的湿度百分比可作为各域分别定义的传感目标。
- **C 环境**可支持输入、故障形态参考，或把未来环境读数定义为环境预测监督。缺植物标签时，不能凭环境预测表现评价植株状态。
- **D 植物生长与农艺**应以实际人工测量日、收获日或仪器输出作为目标。生长插值、GDD、模拟水势和计算光量标注来源，不能计作新增观察。

## 选用顺序

1. **Evolving Testbed** 是方向 A 的主数据。以实测根区湿度为目标，可以检验三个采集活动中的解释表现。2024 土壤水势及 2025 植株传感字段只能作为各自的单季补充。
2. **WUR Tomato Challenge v2** 是最直接的独立外部复现。岩棉 WC 与同隔间气候、累计灌溉能配对，六个不同策略隔间允许组留出。外部结论限同一评估协议能否复现，露地与岩棉之间的统一标定另需验证。
3. **Horti-M3-Tomato** 是同设施跨季温室数据和 C 方向备选。原始植株测量频率低，图像与处理文件不计入已核实标签。若主课题仅用 Evolving 与 WUR，Horti 留作预注册后可选的第三域。

**电生理**另做了第四项深入审查，作为方向 B 的首选备选。它可提供植株留出分类复现，操作性标签和单批数据限制了独立验证范围。跨学科小样本对照 TS_Protocol 的叶水势是真实仪器测量，可以核对机制，但四株同批不足以支撑泛化。 [原件审查与数值](TOP3_DATASET_AUDIT.md)

同一农场旧版和新版 2023 年重复。比利时微气候与首轮水势原包 2019、2020 中心站完全重复。跨库实验先查设备、时间、设施和批次，避免按 DOI 去重后仍发生样本泄漏。
